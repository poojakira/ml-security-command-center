# ML Security Command Center (Design Prototype / Visual Mockup)

[![Dashboard Preview](https://img.shields.io/badge/GitHub_Pages-Preview-blue)](https://poojakira.github.io/ml-security-command-center/)

A single-page HTML dashboard that displays all 11 ML security projects in one view as a **design prototype / visual mockup**. It shows a 3D network graph of the products, their descriptions, and a MITRE ATT&CK technique coverage grid.

This was built as a portfolio visualization piece to illustrate how a unified ML security command center *could* look. It does not perform any actual security monitoring.

## How data is generated

All numbers on the dashboard are fake:

- Metrics (events/min, threats blocked, detection rates) are randomly generated in JavaScript using `Math.random()`
- Values are regenerated every few seconds to simulate activity
- "Live" indicators and the activity feed are cosmetic animations
- The ATT&CK coverage grid is hardcoded, not computed from actual detection results
- There are no WebSocket connections or API calls to real backends

## What's in it

- `index.html` — Main dashboard (Three.js 3D node graph + product cards + ATT&CK grid)
- `dashboard/index.html` — Alternative flat dashboard layout

Both files are self-contained HTML with inline CSS/JS. No build step, no dependencies to install.

## How to view the mockup

**Option A: Just open the file**

Double-click `index.html` in your file explorer. It opens in any modern browser.

**Option B: Serve it locally** (needed if the browser blocks CDN scripts from a `file://` URL)

```bash
cd ml-security-command-center
python -m http.server 3000
# Then open http://localhost:3000
```
